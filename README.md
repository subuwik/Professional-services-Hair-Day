# Hair Day Salon Website

A multi-page static website for the Hair Day boutique hair salon, built with semantic HTML5 and custom CSS.

## Pages

- **Home (`index.html`):** Hero banner, promotional offers and salon overview.
- **Services (`services.html`):** Haircut, coloring and styling packages with pricing.
- **About (`about.html`):** Salon story and team showcase.
- **Contact (`contact.html`):** Location details, working hours and booking inquiry form.
